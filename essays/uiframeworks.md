UI frameworks remind me of functions or methods. While it may be easier for a person to implement certain algorithms using a bunch of if statements, for loops, and while loops instead of learning certain methods such as the slice and reduce methods for an array, it will save a huge amount of time in the future if one just takes the initial time it takes to learn these methods and how to use them. UI frameworks are similar because they inherently provide a lot of shortcuts and tools to make processes easier, so one does not have to purely use languages such as HTML and CSS.
Bootstrap is just one example of a UI framework that makes a lot of tasks easier once learned. For example, justify-start, justify-end, and justify-center can be used in order to align items in the container in just one line of code. Without it, one would need to find another way to do this, likely needing to write more lines of code. UI frameworks also make your code more readable because of the inherent less lines of code. Overall, it does take a lot of time to initially learn the UI framework. Once it is learned, it can be greatly beneficial in the future and save a lot more time than 
one does learning it. Just like learning programming methods such as slice and reduce for arrays in Javascript, UI frameworks provide tools that can be considered 
almost necessary to provide quicker, more efficient, and readable code. So in return for all the time and effort put in, one makes their time back based on the time 
they saved, and is able to help other people they work with in the future with ease.
