## AI in Software Engineering
As times have evolved AI has become more present in software engineering and coding than ever before. AI can be used to cheat by writing essays, doing quizzes, or designing whole programs for someone; however, if used smartly AI can be a great tool to assist one in learning. For software engineering in particular, AI can help one become more familiar with different UI frameworks or putting in self-made code in order to fix errors that one can not solve themself. It can even be beneficial to put in code with no errors because one might find ways to make their code more efficient and readable. Personally, the AI tool I have made use of the most in this course is ChatGPT.

# Using AI Responsibly
Experience WODs e.g. E18
For experience WODs I barely used AI and if I did it was really small. This is because after attempting it myself, there was already a solution posted by one of the instructors that I could watch. I did sometimes post the code I made after the WOD to find out if there was a better solution and ChatGPT sometimes gave me a solution that I had no thought of.
In-class Practice WODs
For the in-class practice WODs I made it a goal to not use AI. This is because I believe it is best to practice on my own and not use AI and get as far as I can without it.
In-class WODs
During the in-class WODs I ended up using AI on most of them, but I always got as far as I could into the WOD by myself. Most of the time I used it to fix the code I had written after attempting the problem instead of giving it the problem itself. For example, in the nextJS WOD 1, I used ChatGPT in order to help me with the dropdown menu as well as fix an error in my code.
Essays
At most, I used AI to brainstorm some ideas, but never to write an essay itself. I did not use it for an essay because I think I am already adept at writing due to my experience working as an article writer for various websites.
Final project
For the final project, the main use of AI was actually not for code, but in order to fix github and Vercel errors. ChatGPT helped my group and I better understand these errors and when similar errors occurred we knew how to deal with them.For example, one time a merge was not going through I asked ChatGPT how to fix it and afterwards, we were able to merge the branch to main.
Learning a concept / tutorial
I use ChatGPT to assist with this on numerous occasions for coding and topics outside of this class. This especially helps by asking it to create similar questions for study guides. For example, I gave ChatGPT a question from my physics study guide and asked it to create 2 similar questions I could solve. This way, I could make sure I understood the material.
Answering a question in class or in Discord
I have not used AI for this because I do not think it is necessary to do so and it is best to either let someone else answer or try to answer the question yourself to obtain a better understanding.
Asking or answering a smart-question
I have not used AI for this because I find the language that AI uses to ask questions hard to interpret for some people compared to speaking normally.
Coding example e.g. “give an example of using Underscore .pluck”
I have used this in the class for various examples of array functions such as .slice. I think this helps gain some understanding of when to use certain functions, but it is especially useful in algorithms knowing the patterns of when to use different algorithms helps with solving leetcode problems.
Explaining code
I use ChatGPT to explain code whenever I do not understand how it works. I think this is especially important for learning, as if one just uses AI to write code without understanding the concepts then they will probably fall behind in the future.
Writing code
I try to avoid this, but as a last resort I ask ChatGPT to write code. This is because I think it is important to rely on your own skill first in order to practice and get a job in the future.
Documenting code
I have used it to keep records of past codes so I can ask for it if I mess up, but I have stopped doing this after the use of vscode and github desktop.
Quality assurance e.g. “What’s wrong with this code <code here>" or “Fix the ESLint errors in <code here>”

I use this all the time when I read an error and can not quite solve it, but it is important when doing this to understand how it fixes the error, so you can solve the error yourself when you encounter it again.
Other uses in ICS 314 not listed
I can not think of any other way to use AI in ICS 314, as I think they were all covered in the above examples.

## The Future of AI in Education
Before this course, I think I overused AI and it definitely hindered my learning. Luckily, I came into this course with a better understanding and it has enhanced my learning experience. I think it can be a trap for some people who rely on it too much, but when used the right way, it is one of the most valuable tools for anybody looking to learn something. With AI, I was able to learn and grasp concepts at a speed I have never been able to before.
AI’s practical applications are being seen all over right now. Of course learning or studying new topics, but also cooking, security, and more. AI probably is not the best at addressing new software engineering challenges, but is great at teaching those who do not know problems that have been solved prior. As far as limitations go with AI in this course, I believe that I have not had any major limitations I can think of because it is just amazing and helped me an incredible amount.
As far as software engineering goes, I believe that the AI enhanced course far surpasses the traditional teaching methods. The danger is some students may be over reliant on it, but I believe most students with AIcan learn knowledge, retain it, and develop new skills faster than ever. As far as engagement goes, I do not believe one offers significantly more engagement than the other.
The future of AI is limitless. ChatGPT-5 is already being made, and I believe that nobody truly knows what it could do for the future of software engineering. It has already done so much, and I believe it will make software engineering surpass whatever limits it has.
AI has proven to be an invaluable tool in the Software Engineering course, offering numerous opportunities to enhance learning and problem-solving. While it can be misused, responsible AI use enables students to learn quickly, improve code efficiency, and overcome difficulties effectively. My experience with AI has demonstrated its potential to accelerate understanding and skill development when used thoughtfully. Moving forward, I recommend promoting cautious use of AI, ensuring students develop both proficiency and a solid foundation in software engineering principles.
